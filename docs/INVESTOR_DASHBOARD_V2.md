# AlphaScope Investor Dashboard V2

Status: active Sprint 1 source of truth.

## Objective

Transform AlphaScope from a report-centric interface into an investor-centric dashboard that helps long-term and dividend-oriented investors identify, compare, and understand ranked opportunities.

## Constraints

- Preserve the existing Python pipeline, PostgreSQL persistence, static web dashboard, Cloudflare Pages deployment path, automation pipeline, Telegram delivery, and AlphaScope branding.
- Reuse existing collectors, database models, scoring code, and web export architecture whenever possible.
- Do not add new collectors, new AI providers, broker integrations, portfolio tracking, authentication, or trading workflows.
- Keep existing intelligence/report functionality available as an Analyst Dashboard.
- Prefer additive and backward-compatible data contract changes.

## Current Baseline

- The AlphaScope run is orchestrated by `app/main.py`.
- FMP quotes, company profiles, and fundamentals are already collected by existing collectors.
- Fundamentals are persisted to `fundamental_snapshots`.
- Investor scores are generated by `app/analytics/investor_scoring_engine.py`.
- Ranked opportunities are built by `app/analytics/investor_ranking.py`.
- Investor scores are persisted to `investor_scores`.
- Static web exports are generated by `app/renderers/web_export.py`.
- `web/index.html` is the current dashboard home.
- `web/intelligence.html` is the detailed intelligence report page.
- `web/opportunity.html` is the symbol-level opportunity detail page.

### 2. Enrich Investor Rankings

Investor rankings must include:

- Company name
- Sector
- Current price
- Dividend yield
- Buy Score
- Recommendation
- Valuation Score
- Dividend Score
- Financial Quality Score
- Price Position Score
- Technical Score
- P/E ratio
- ROE
- Debt-to-equity
- Free cash flow
- RSI
- SMA20
- SMA50
- SMA200
- Distance from 52-week low

Missing data should be represented as `null` in JSON and rendered as `--` in the dashboard.

### 3. Buy Score Explanation

Add investor-friendly explanation UX:

- Buy Score tooltip explaining components and weights.
- Score breakdown modal for each ranked opportunity.
- Deterministic explanation bullets for strengths, risks, and missing data.
- No additional AI call is required for explanations.

Current score components:

- Valuation
- Dividend
- Financial quality
- Price position
- Technicals

Current recommendation thresholds:

- `BUY_SCORE >= 80`: Strong Buy
- `BUY_SCORE >= 65`: Buy
- `BUY_SCORE >= 50`: Watch
- Otherwise: Avoid

### 4. Homepage Redesign

First screen should show:

- Market Snapshot
- Investor Rankings

Market Snapshot should include:

- Market regime
- Confidence
- Last update
- Concise summary

Investor Rankings should include:

- Rank
- Company
- Sector
- Current price
- Dividend yield
- Buy Score
- Recommendation

The homepage should preserve:

- AlphaScope branding
- Dark visual style
- Ticker strip where useful
- Responsive behavior
- Static JSON fetch approach

### 5. Analyst Dashboard Separation

Move the detailed intelligence experience into a separate Analyst Dashboard page.

Required behavior:

- Label it as Analyst Dashboard in navigation and links.
- Preserve existing full-report loading.
- Do not remove intelligence report generation or exports.

Extend the existing Telegram summary with a `TOP OPPORTUNITIES` section.

Include the top 5 ranked opportunities:

- Symbol

- Recommendation

## Static Data Contracts

### `web/data/investor-rankings.json`

Required top-level fields:

- `generated_at`
- `generated_at_iso`
- `generation_status`
- `count`
- `rankings`

Each ranking row should include the enriched ranking fields listed above plus deterministic explanation fields:

- `strengths`
- `risks`
- `missing_data`

### `web/data/latest-report.json`

Keep existing fields and add:

- `top_opportunities`

This should contain a compact subset of the highest-ranked investor opportunities.

### `web/data/full-report.json`

Keep existing report fields and preserve backward compatibility for the Analyst Dashboard.
